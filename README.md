# 日课 · 把一天过成一件件做完的事

一个只在自己手机上运行的日常应用：把今天要推进的事、正在专注的时间、随手冒出的想法、睡前的两句复盘，收进同一个地方。

不联网、不注册、不上传。数据存在本机，随时可以导出成 JSON 带走。

## 为什么做它

日常最消耗人的不是难事，是「散」。事情散在备忘录、微信收藏、脑子里，一天结束不知道时间去哪了。

日课只做四件事，并把它们连成一条线：

- **今日**：进门先看见现在几点、今天还剩几件、下一件是什么
- **待办**：今天 / 以后 / 已完成三档，长按删除，写完不占脑子
- **专注**：15 / 25 / 50 分钟，切走页面也继续计时，完成自动入账
- **记录 + 复盘**：想法随手丢进去；睡前写做成了什么、卡在哪、明天第一件

「我的」页把这些攒成数据：本周完成待办、专注时长、连续有进展的天数、近 7 天专注分布。

## 安装

1. 手机打开本仓库，下载 `dist/rike.apk`
2. 允许「安装未知来源应用」后完成安装
3. 打开即用，无需登录

也可以在手机上直接访问：

```
https://github.com/zachshi-ai/rike/raw/main/dist/rike.apk
```

## 设计

- 深色底 + 酸绿强调色，大字号时间做主视觉，信息密度克制
- 底部悬浮胶囊导航，五个页签，回退键在子页时先回「今日」
- 无网络权限申请，除导出用的存储写入外不申请任何敏感权限
- 单手可达：所有主操作在拇指区内
